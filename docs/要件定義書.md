# 要件定義書 — LifeTrace（人生体験シェア・体験アプリ）

## 1. 概要

個人個人の人生体験（出来事・選択・感情・転機など）を入力し、それを構造化されたデータとして蓄積・可視化することで、他のユーザーが「他人の人生を追体験する」ことができるモバイルアプリケーション。

## 2. 背景・目的

- 個人の人生経験は、本人にとっては当たり前でも、他者にとっては貴重な学びや気づきの源になる。
- 従来のブログ/SNSは断片的な投稿が中心で、「一人の人生の軌跡」を通して読む体験は提供できていない。
- 本アプリは、ユーザーが自分の人生上の出来事を時系列・カテゴリ別に記録し、それをタイムライン／グラフとして可視化し、第三者が他人の人生をストーリーとして閲覧・追体験できる場を提供する。

## 3. 想定ユーザー

| ユーザー区分 | 説明 |
|---|---|
| 投稿者（語り手） | 自分の人生体験を記録・公開するユーザー |
| 閲覧者（追体験者） | 他人の人生体験を読み、追体験するユーザー |
| ※多くのユーザーは両方の役割を兼ねる想定 |

## 4. 用語定義

| 用語 | 定義 |
|---|---|
| ライフイベント | ユーザーが記録する人生上の1つの出来事（出生、入学、転職、結婚、挫折、達成 等） |
| ライフライン | ユーザーのライフイベントを時系列に並べたタイムライン全体 |
| 追体験 | 他人のライフラインを閲覧し、感情移入しながら読む行為 |

## 5. 機能要件

### 5.1 アカウント・認証
- メールアドレス／Googleアカウント／Appleアカウントによる新規登録・ログイン
- プロフィール編集（表示名、アイコン、自己紹介、公開範囲設定）

### 5.2 ライフイベント入力
- ライフイベントの新規作成（タイトル、本文、発生年月、カテゴリ、感情タグ、画像添付）
- カテゴリ例：学業、仕事、家族、恋愛、健康、挑戦、挫折、達成、転居 など（カスタムタグ追加可）
- 感情タグ（例：嬉しい、辛い、不安、誇り 等）を選択し、感情の起伏をデータ化
- 公開範囲設定（全体公開／フォロワー限定／非公開）
- イベントの編集・削除

### 5.3 データ化・可視化
- 1人のライフイベントを時系列タイムラインとして表示
- 感情タグの推移を「感情グラフ（人生の浮き沈みグラフ）」として可視化（横軸：年齢/年月、縦軸：感情スコア）
- カテゴリ別の件数・比率をグラフで表示（円グラフ／棒グラフ）
- 人生の転機（ターニングポイント）をハイライト表示

### 5.4 追体験（閲覧）機能
- 他ユーザーのライフラインを時系列に沿って1件ずつ読み進める「追体験モード」
- 追体験モードでは、その人が体験した順番・感情の起伏に沿ってストーリーのように閲覧できるUI（ページ送り形式）
- いいね・コメント・共感スタンプ（「わかる」「感動した」等）
- 似た体験を持つ人のライフイベントをレコメンド

### 5.5 検索・発見
- カテゴリ／年代／感情タグでのライフイベント検索
- 「同じ体験をした人」を検索する機能（例：転職経験、留学経験 等のタグ検索）
- 注目のライフライン（人気・話題）のフィード表示

### 5.6 通知
- フォローしているユーザーの新規ライフイベント投稿通知
- コメント・いいねの通知

## 6. 非機能要件

| 区分 | 要件 |
|---|---|
| 対応OS | iOS 15以上 / Android 8.0(API26)以上 |
| 性能 | タイムライン読み込みは2秒以内を目標 |
| セキュリティ | 非公開設定のデータは本人とアクセス許可者以外参照不可。Firebase Authによる認証必須 |
| プライバシー | 個人を特定できる機微情報（病歴・本名等）の取り扱いに関するガイドラインをアプリ内に明示 |
| 可用性 | Firebaseのマネージドサービスを利用し、運用負荷を最小化 |
| 多言語 | 初期リリースは日本語のみ。将来的に英語対応を検討 |

## 7. 制約条件

- 個人開発（小規模チーム）を前提とし、MVPはFirebaseを用いたサーバーレス構成とする
- 初期リリースはモバイル（Flutter／iOS・Android）のみ。Web版は将来検討

## 8. スコープ外（初期リリースでは対応しない）

- 動画投稿・編集機能
- AIによる自動文章生成・要約
- 多言語翻訳機能
- 課金・サブスクリプション機能

## 9. 今後の検討事項

- センシティブな人生体験（死別、病気等）に関するコンテンツモデレーション方針
- 未成年ユーザーの利用ガイドライン
