## 0. 提出の前に（必須）

**Firestore のルールを先にデプロイしてください。** 古いルールのままだと、審査員がアカウント削除を試したときに、ほかの人から届いたコメントを削除できずにエラーになります。

```
firebase login
firebase deploy --only firestore:rules
```

- 新しいルールでは、非公開・フォロワー限定の記録をサーバー側でも読めなくなります。
- 影響：1.1.0 以前のアプリでは、ほかの人のページ（タイムライン・追体験・感情グラフ）が表示できなくなります。ホーム・さがす・自分のページは今までどおり使えます。1.2.0 に更新すれば解消します。

## 1. このバージョンの新機能（必須・4000文字以内）

```
「人生は、誰かのヒントになる」
経験を語る・読む・返すことが、もっと自然にできるようになりました。

■ 新機能
・経験で応える「応答記録」
　心が動いた記録から「この記録に応えて、自分の経験を記録する」を選ぶと、元の記録とつながった記録を書けます。公開すると元の記録の下に並び、書いた人にお知らせが届きます。
・書き方のヒント
　本文に「状況・迷い・選択・その後・今思うこと」の5つの問いを入れるボタンを追加しました。
・今の状況から探す
　「進路や転職に迷っている」「先が見えず不安」などから、自分に近い経験を探せます。ジャンル・気持ち・出来事が起きた年代を組み合わせて絞り込めます。
・追体験モードで「転機だけ」をたどれるように
・感情グラフに「谷からの回復」を追加
　つらい出来事のあと、どうやって気持ちが上向いたかが分かります。
・誕生月と12月に、一年のふり返りをご案内
・プッシュ通知
　気持ち・コメント・フォロー・応答記録が届いたときにお知らせします（設定から有効にできます）。

■ 安心して使うために
・公開する前に、電話番号やメールアドレスなど個人が分かる情報がないか確認するようにしました
・新しい記録は「非公開」から始まります。気持ちの整理がついてから公開できます
・アカウントを削除すると、記録を含むすべてのデータが削除されるようになりました
・非公開やフォロワー限定の記録が、ほかの人から見えてしまうことがある問題を修正しました

■ 改善
・記録の詳細で「いいね」「わかる」「感動した」を選べるように
・コメントに書いた人の名前を表示
・生年月を登録している人の記録に「28歳ごろ」のような当時の年齢を表示
・フォローしたときに、相手のフォロワー数が正しく増えるように修正
```

### メモ（英語・審査員向け）

```
LifeTrace lets users record their own life events, reflect on them with an "emotion graph", and share them so that others can read and relive their life stories.

What's new in 1.2.0 and how to review:
1. Sign in with the demo account provided above.
2. Response records: open any post by another user from the Home tab and tap "この記録に応えて、自分の経験を記録する" (Respond with your own experience). The form links the new record to the original one.
3. Writing hint: in the record form, tap "書き方のヒント（5つの問い）を入れる" to insert guiding questions into the body.
4. Privacy check: if the text contains a phone number or email address and the visibility is not private, a confirmation dialog appears before saving.
5. Search: the "さがす" tab now has situation-based shortcuts and combined filters (category, feeling, age decade).
6. Push notifications (optional): Settings > "プッシュ通知". Notifications are sent when another user reacts, comments, follows, or responds.

User-generated content safeguards (Guideline 1.2):
- Users must agree to the Terms of Use, which prohibit objectionable content, before signing up.
- Posts and users can be reported via the flag icon on a post or the "..." menu on a user page. Reports are reviewed by the developer within 24 hours; objectionable content is removed and the offending account is suspended.
- Users can block abusive users; blocked users' posts are hidden from feed and search.

Account deletion (Guideline 5.1.1(v)): Settings > "アカウントを削除". After confirming with the password, the account and all of the user's data (records, comments and reactions on them, follows, notifications, profile) are deleted.

The app is in Japanese.
```

## 6. 提出手順

1. **0 のルールのデプロイを済ませる**
2. App Store Connect →「マイ App」→ LifeTrace を開く
3. 左上の「＋」→「iOS」→ バージョン **1.2.0** を作成
4. 「このバージョンの新機能」に **1** を貼り付け、必要に応じて **2・3** を更新
5. 「ビルド」欄で **1.2.0 (8)** を選択（処理が終わるまで10〜30分ほどかかります）
   - 輸出コンプライアンスを聞かれたら「標準の暗号化のみ（HTTPS）」に該当するため、「いいえ（免除対象）」で回答
6. 「App Review に関する情報」にデモアカウントと **5** のメモを入力
7. 画面上部の「保存」→「審査用に追加」→「審査に提出」

## 7. プッシュ通知を実際に届けるための設定（審査とは別・任意）

アプリ側の準備は済んでいます（設定の「プッシュ通知」、送信先の登録、iOS の Push Notifications 権限）。実際に通知を送るには次の3つが必要です。

1. **Firebase を Blaze プラン（従量課金）に変更**：Cloud Functions は無料の Spark プランでは使えません。この規模なら無料枠内に収まる見込みですが、予算アラートの設定をおすすめします。
2. **APNs 認証キーを登録**：Apple Developer →「Certificates, Identifiers & Profiles」→「Keys」で APNs キー（.p8）を作成し、Firebase コンソール →「プロジェクトの設定」→「Cloud Messaging」→「Apple アプリの構成」にアップロード。
3. **関数をデプロイ**：
   ```
   cd functions && npm install && cd ..
   firebase deploy --only functions
   ```

これらが済むまでは、プッシュ通知を有効にしても通知は届きません（アプリ内の「お知らせ」は今までどおり届きます）。
