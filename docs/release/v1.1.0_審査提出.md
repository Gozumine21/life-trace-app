## 1. このバージョンの新機能（必須・4000文字以内）

```
「人生は、誰かのヒントになる」
自分の人生経験を記録して振り返り、ほかの人の人生経験と分かち合う。LifeTraceの考え方がより伝わるよう、使い方の説明と操作性を大きく改善しました。

■ 新機能
・「LifeTraceの使い方」ページを追加
　記録 → 振り返り → 共有 → 追体験 → 共感 の流れを、コツや具体例とともに紹介します。ページから「記録してみる」「感情グラフを見る」「さがしてみる」へ直接進めます。
・はじめのガイドを追加
　初めて起動したときに、アプリの考え方と使い方を5ページで紹介します。
・「記録する」ボタンをいつでも押せる場所に表示
・お知らせの未読件数を表示、「すべて既読」に対応

■ 改善
・記録画面を5つのステップに整理しました
　いつ？ → 何があった？ → どんな気持ち？ → どんなジャンル？ → 誰に見せる？
　年月はタップで選択、気持ちやジャンルは絵文字で選べます。入力途中で戻るときは確認を表示します。
・公開範囲ごとに「誰に見えるか」を説明
・感情グラフに読み方の説明を追加
・追体験モードに進み具合を表示
・ほかの人のページに「追体験する」「感情グラフ」ボタンを追加
・エラー時の案内を分かりやすく改善
・ダークモードに対応
・対応OSを iOS 15.0 以降に変更
```

## 3. 説明（任意で更新・4000文字以内）

現在の説明文を置き換える場合に使用します。

```
LifeTraceは、あなたの人生経験を記録して振り返り、ほかの人の人生経験と分かち合うアプリです。

うれしかったことも、つらかったことも、あなたの経験は同じような場面にいる誰かの支えやヒントになります。そして、ほかの人の人生にふれることで、自分では経験できなかった人生を追体験できます。

■ 自分の人生を記録する
入学・就職・引っ越し・出会い・別れなど、人生の出来事を「ライフイベント」として残せます。
いつ・何があって・どう感じたかを、5つのステップで簡単に記録。写真も添えられます。

■ 感情グラフで振り返る
記録した気持ちが「人生の浮き沈みグラフ」になります。つらい時期をどう乗り越えたか、何を大切にしてきたかが見えてきます。人生の転機になった出来事もひと目で分かります。

■ 経験を分かち合う
記録ごとに公開範囲を選べます。
・全体公開：誰かの参考になってほしい経験に
・フォロワー限定：家族や友人など身近な人に
・非公開：自分だけの日記に

■ ほかの人の人生を追体験する
ジャンル（学業・仕事・家族・挑戦・挫折など）や気持ちでライフイベントを探せます。「追体験モード」では、ある人の人生を古い順に1つずつ、物語のように読み進められます。

■ 気持ちを伝え合う
「いいね」「わかる」「感動した」やコメントで、書いた人に気持ちを届けられます。

■ こんな使い方も
・進路や転職に迷ったとき、同じ道を歩んだ人の経験を読む
・つらい時期を乗り越えた人の記録から、前に進む勇気をもらう
・自分の歩みを家族に残す
・誕生日や年末に、これまでの人生を振り返る

■ 安心して使うために
ニックネームで利用できます。不適切な投稿やユーザーは通報・ブロックできます。アカウントはアプリ内から削除できます。
```

## 7. 提出手順

1. App Store Connect →「マイ App」→ LifeTrace を開く
2. 左上の「＋」→「iOS」→ バージョン **1.1.0** を作成
   （ビルド 6 で 1.1.0 を作成済みの場合は、そのバージョンを開く）
3. 「このバージョンの新機能」に **1** を貼り付け
4. 必要に応じて **2〜5** を更新
5. 「ビルド」欄で **1.1.0 (7)** を選択（ビルド 6 を選んでいたら 7 に差し替え）
   - 輸出コンプライアンスを聞かれたら「標準の暗号化のみ（HTTPS）」に該当するため、「いいえ（免除対象）」で回答
6. 「App Review に関する情報」にデモアカウントと **6** のメモを入力
7. 画面上部の「保存」→「審査用に追加」→「審査に提出」
