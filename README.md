# LifeTrace

人生の出来事を「ライフイベント」として記録し、感情グラフで振り返り、ほかの人の人生を追体験できるアプリです。

現在のバージョン: **1.1.0**（変更点は [CHANGELOG.md](CHANGELOG.md)）

## 考え方：人生は、誰かのヒントになる

LifeTrace は、**自分の人生経験**を記録して振り返り、それを**ほかの人の人生経験**と分かち合うアプリです。
うれしかったことも、つらかったことも、あなたの経験は同じような場面にいる誰かの支えになります。
そして、ほかの人の人生にふれることで、自分では経験できなかった人生を追体験できます。

使い方は次の循環です。

**✍️ 記録 → 📈 振り返り → 🌱 共有 → 📖 追体験 → 🤝 共感 →（また自分の記録へ）**

## 使い方

初めて起動すると、はじめのガイド（5ページ）が表示されます。
アプリ内の詳しい説明は、ホーム右上の「？」または「設定 → LifeTraceの使い方」から開けます。

### LifeTraceで大切にすること

LifeTraceは、人生経験を一方的に発信する場所ではなく、**自分の経験を残し、他の人の経験にふれ、感じたことを返す**ための場所です。自分と他人の人生を比べるのではなく、それぞれの背景や感じ方の違いを知るために使います。多くのユーザーは、経験を語る人と追体験する人の両方になります。

### 1. アカウントを作る
ログイン画面の「無料でアカウントを作成」から、表示名・メールアドレス・パスワードの3項目を入力します。

### 2. 出来事を記録する
画面右下の **「記録する」** ボタンを押し、表示される5つのステップに沿って入力します。

| ステップ | 内容 |
| --- | --- |
| ① いつの出来事？ | 年と月をタップで選びます（おおよそで大丈夫です） |
| ② 何があった？ | タイトルと本文を書きます |
| ③ どんな気持ちだった？ | 😊 などの気持ちを1つ選びます。感情グラフの高さになります |
| ④ どんなジャンル？ | 📚学業・💼仕事などから選びます |
| ⑤ 誰に見せる？ | 全体公開／フォロワー限定／非公開（自分だけ） |

特に大切な出来事は「人生の転機としてマークする」をオンにすると、グラフや一覧で目立つように表示されます。写真も追加できます。

最初から詳しく書く必要はありません。まずは非公開で書き始め、あとから内容や公開範囲を見直すこともできます。誰かの経験を含める場合は、本人が特定される情報やプライバシーを無断で公開しないでください。

記録のコツ：入学・就職・引っ越し・出会い・別れなど、人生の節目から書くと始めやすいです。うまく書こうとせず、そのとき何があり、どう感じたかを素直に残しましょう。

### 3. 振り返る
「マイページ」→「感情グラフ」で、気持ちの浮き沈みやジャンルの割合を見られます。つらい時期のあとに何があったか、どう乗り越えたかに気づけます。

### 4. 経験を分かち合う
記録ごとに、誰に見せるかを選べます。あとから変更もできます。

| 公開範囲 | 向いている使い方 |
| --- | --- |
| 全体公開 | 誰かの参考になってほしい経験 |
| フォロワー限定 | 家族や友人など、身近な人に伝えたい経験 |
| 非公開 | 自分だけの日記 |

他人の実名や、住所・勤務先など個人が分かる情報は書かないようにしましょう。

### 5. ほかの人の人生にふれる
- **ホーム**: みんなが公開したライフイベントが新しい順に並びます
- **さがす**: ジャンルや気持ちで探せます
- ユーザーのページで **「追体験する」** を押すと、その人の人生を1つずつめくって読めます。❤️いいね／🤝わかる／🥹感動した で気持ちを伝えましょう
- **お知らせ**: いいね・コメント・フォローが届くと、下部メニューに件数が表示されます

### 5. 経験を分かち合う

誰かの経験を読んで自分にも似た出来事があれば、自分のライフイベントとして記録してみましょう。同じ経験でも感じ方や選択は人によって異なります。コメントやリアクションは、相手の経験を決めつけず、「読んでこう感じた」という形で返すと、次の共有につながります。

#### 公開範囲の選び方

| 公開範囲 | 向いている使い方 |
| --- | --- |
| 非公開 | 自分だけの日記として整理する。公開前の下書きにも使う |
| フォロワー限定 | 見守ってくれる人や、継続して交流したい人と共有する |
| 全体公開 | より多くの人に経験を届け、共感や新しい気づきを得る |

読んだ感想は ❤️・🤝・🥹 やコメントで伝えましょう。人生の選択に正解はありません。相手の経験を否定せず、尊重して言葉を選んでください。

### こんな使い方も
- 進路や転職に迷ったとき、同じ道を歩んだ人の経験を読む
- つらい時期を乗り越えた人の記録から、前に進む勇気をもらう
- 自分の歩みを「フォロワー限定」で家族に残す
- 誕生日や年末に、これまでの人生をグラフで振り返る

困ったユーザーがいる場合は、ユーザーページ右上の「︙」からブロック・通報ができます。

- Flutter 3.44 / Dart 3.12、状態管理は Riverpod、画面遷移は go_router、バックエンドは Firebase（Auth / Firestore）

```sh
flutter pub get
./start-emulator.sh   # Firebase エミュレータを起動（ローカル開発時）
flutter run
flutter analyze && flutter test
```
